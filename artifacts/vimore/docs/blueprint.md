# **App Name**: ViMore

## Core Features:

- User Authentication: Secure user registration, login, and session management.
- User Profiles: Create and customize user profiles with personal information and a profile picture.
- Real-time Post Creation: Allow users to create and publish text-based posts, optionally with attached images, displayed instantly to followers.
- Dynamic Feed Display: Display a personalized, real-time feed of posts from followed users, ensuring new content appears promptly.
- Direct Messaging: Enable real-time private messaging between individual users.
- Follow/Unfollow Functionality: Users can follow other users to see their content and unfollow them.
- AI Post Enhancement Tool: An AI tool that suggests relevant hashtags or offers brief summary prompts to enhance user-created posts.

## Style Guidelines:

- Primary color: A modern, inviting violet (#9940E5), representing connection and creativity, contrasting nicely with a light background.
- Background color: A soft, almost white lavender (#F2ECF7), providing a clean and calming canvas.
- Accent color: A vibrant, clear blue (#6E96FF), used for calls to action, highlights, and interactive elements to draw attention.
- Headline font: 'Space Grotesk' (sans-serif) for a contemporary, slightly tech-inspired feel. Body font: 'Inter' (sans-serif) for excellent readability across all text lengths.
- Use minimalist, outline-style icons to maintain a clean and modern aesthetic that complements the overall design.
- Implement a clean, card-based layout for posts and profiles, ensuring content is well-organized and easy to scan. Prioritize intuitive navigation for key features.
- Incorporate subtle and smooth transitions for feed updates, new post notifications, and user interactions to create a fluid user experience.
